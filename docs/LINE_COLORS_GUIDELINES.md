# 路線カラーと列車種別カラーの設計指針

本ドキュメントでは Trainfo プロジェクトにおける各路線の基本カラー（`lineColor` / `accentColor`）および列車種別カラー（`trainTypes[type].bgColor` / `textColor`）の設定方針と、実装時に遵守すべきデザインと視認性のルールを定義します。

---

## 1. 基本思想

Trainfo では、地図上のポリライン・列車マーカー・タイムライン・時刻表バッジにおいて利用者が直感的に路線や種別を識別できるよう、各鉄道事業者が駅掲出の時刻表・路線図・車両案内表示（方向幕・LCD）で使用している公式カラーを忠実に再現することを原則とします。

一方で、白背景のカードや濃色のバッジ上で文字が読めなくなる事態を防ぐため、WCAG コントラスト基準を意識した明度・彩度調整を併用します。

---

## 2. カラープロパティの役割分担

各路線定義（`src/data/lines/<lineId>/index.ts` および `trainTypes.ts`）には、以下の4つのカラープロパティが存在します。

| プロパティ名 | 主な使用箇所 | 設定基準 |
| :--- | :--- | :--- |
| `lineColor` | 地図上の路線ポリライン、路線選択ボタンのテーマ色、駅詳細パネルのヘッダー帯 | 各路線の公式コーポレートカラーまたは路線記号カラーを設定します（例: JR山手線 `#80c241`、東京メトロ銀座線 `#f39700`、東武東上線 `#004098`、東武スカイツリーライン `#226bb8`）。 |
| `accentColor` | 路線ポリラインのハイライト・縁取り、グラデーションや強調表示要素 | 原則として `lineColor` と同色、またはその路線の代表的な優等種別カラー・副次シンボルカラーを設定します（例: JR中央線は `lineColor: #eb5c01` に対し `accentColor: #c9252d`、JR東北新幹線ははやぶさグリーン `#41934c` に対しはやぶさピンク `#e4007f`）。 |
| `trainTypes[key].bgColor` | 地図上の列車アイコンの背景、列車詳細パネルの種別バッジ、駅時刻表の種別インジケーター | 各事業者の公式停車駅案内図・時刻表における種別色を設定します。 |
| `trainTypes[key].textColor` | 種別バッジ内のテキスト色 | 原則として白（`#ffffff`）を使用します。背景色が高明度（黄色 `#ffd400` や `#ffcc00` 等）の場合は、視認性確保のため濃色（`#1e293b` 等）を指定します。 |

## 3. 各駅停車・普通列車および運行カテゴリの分類

Trainfo に収録されている全174路線の配色構成は、路線特性と公式案内の慣例に従い以下の4カテゴリに分類されます。

### カテゴリA: 単一種別のみ運行する路線（19路線）

各駅停車または普通列車のみで運行される路線群です。原則として `lineColor` と基本種別の背景色が一致しており、地図上の路線ポリラインと列車アイコンの色が統一されています（東武各支線は東武公式の普通列車色 `#1e1c1c` に統一しています）。

対象路線は JR山手線、JR鶴見線、JR久留里線、JR磐越東線、JR東海道本線（美濃赤坂線）、JR太多線、JR名松線、JRゆめ咲線、JR草津線、JR小浜線、JR加古川線、JR和田岬線、JR関西本線（亀山～加茂）、東京メトロ銀座線、東京メトロ丸ノ内線、東武亀戸線、東武大師線、東武小泉線、東武越生線の19路線です。

### カテゴリB: 各駅停車を路線カラーとし優等種別を固有カラーとする路線

各駅停車または普通列車に路線カラーを割り当て、快速・急行・特急などの優等種別に各社の公式識別色を割り当てる標準的な構成です。JR京浜東北線・根岸線（`#00b2e5`）、JR埼京線（`#00ac84`）、東京メトロ日比谷線・東西線・千代田線・有楽町線・半蔵門線・南北線・副都心線、小田急各線（`#2288cc`）、相鉄各線（`#041452`）などが該当します。

### カテゴリC: 各駅停車・普通に公式の専用色を割り当てる路線

路線カラーが優等種別に使用されている路線や、公式の案内図において普通列車・各駅停車に固有の色が定められている路線では、路線カラーより公式の種別色を優先します。

| 対象路線 | 普通・各駅停車の設定 | 路線カラー・優等種別などとの住み分け |
| :--- | :--- | :--- |

## 4. 優等種別のカラー設定規約と共通プリセット

同一路線内に複数の優等種別が存在する場合は、共通定数およびプリセット定義（`src/data/trainTypePresets.ts`）を参照して色ズレを防ぎます。

| プリセット定数 | 定義されている主な種別カラー |
| :--- | :--- |
| `LIMITED_EXP_PRESETS` | 首都圏標準レッド（`STANDARD: #d32f2f`）、中央線系統ワインレッド（`CHUO: #be123c`）、新潟系統夕日柿色（`NIIGATA: #c2410c`）、常磐線レッド（`JOBAN: #e60012`）、房総ブルー（`BOSO: #0074be`）、房総・京葉クリムゾン（`CRIMSON: #c9252d`）、東武特急レッド（`TOBU: #c8102e`）、小田急ロマンスカーのバーミリオンオレンジ（`ODAKYU: #dd3c00`） |

| `CHUO_PRESETS` | 各駅停車グレー（`LOCAL: #475569`）、快速オレンジ（`RAPID: #eb5c01`）、通勤快速パープル（`COMMUTER: #9333ea`）、中央特快・特別快速スカイブルー（`CHUO_SPECIAL_RAPID` / `SPECIAL_RAPID`: `#0284c7`）、青梅特快グリーン（`OME_SPECIAL_RAPID: #16a34a`）、通勤特快レッド（`COMMUTER_SPECIAL_RAPID: #dc2626`） |

## 7. 新規路線追加時のカラー設計チェックリスト

新しく路線を `src/data/lines/` に追加する際は、以下の項目を確認します。

1. `lineColor` は事業者の公式路線図・駅ナンバリング記号の色と一致しており、地図背景（標準マップ・ダークマップ双方）の上で視認できる彩度とコントラストを備えていること。
2. 公式駅ナンバリングが存在する路線のみ `Station.stationNumber` と `Badges.tsx` の `STATION_BADGE_COLORS` に記号と配色を追加し、公式未制定路線では未設定のままにすること（詳細は [docs/ROUTE_EXPANSION_PLAYBOOK.md](ROUTE_EXPANSION_PLAYBOOK.md) 第33条を参照）。
3. 時刻表JSON内に登場するすべての `trainType` キーが `trainTypes.ts` に漏れなく定義されており、高明度背景色（`#ffd400`, `#ffcc00` 等）では濃色の `textColor` を指定していること。
4. 直通運転を行う路線間で、共通運行される種別（S-TRAIN、THライナー、東武〜野岩〜会津直通など）の配色が統一されていること。
