# Trainfo ラインカラー＆アクセントカラー選定ガイドライン

本ドキュメントは、Trainfo において各路線の `lineColor`（メインラインカラー）および `accentColor`（アクセントカラー）を決定・保守する際の選定方針、典拠、および全路線の選定根拠をまとめた仕様基準書です。

---

## 1. 選定の基本理念

Trainfo は、首都圏・甲信越・神奈川を中心とする多数の鉄道事業者が同一マップ上に描画されるリアルタイム運行シミュレーターです。  
地図上での視認性の確保と、駅名標や車体サインシステムなどの**実世界の案内標識との親和性**を両立するため、統一された基準に基づいてカラーコードを定めています。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ LineDefinition (src/types/index.ts)                                    │
│ ├── lineColor   : 公式サインシステム・運行情報に基づく「基本ラインカラー」       │
│ └── accentColor : 速達種別・直通相手路線・車両帯ツートン等の「副象徴カラー」     │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 2. メインラインカラー（lineColor）の選定基準

メインラインカラーは、原則としてニコニコ大百科「[鉄道路線のラインカラー一覧](https://dic.nicovideo.jp/a/%E9%89%84%E9%81%93%E8%B7%AF%E7%B7%9A%E3%81%AE%E3%83%A9%E3%82%A4%E3%83%B3%E3%82%AB%E3%83%A9%E3%83%BC%E4%B8%80%E8%A6%A7)」に掲載された各社公式情報抽出カラーコード（HEX値）に準拠します。

### 各社別の抽出元と選定原則
1. **JR東日本**:
   * 駅ナンバリング導入線区: JR東日本公式運行情報ページおよび駅ナンバリング仕様のカラーコードを採用。
   * その他線区: 運行情報・路線図に準じた公式カラーを採用（川越線 `#a6a9ab`、八高線 `#a09d95` など）。
2. **東京メトロ**:
   * 駅ナンバリング導入記号の公式カラーコードに準拠（千代田線 `#00bb85`、有楽町線 `#c1a470`、副都心線 `#9c5e31`）。
3. **東武鉄道**:
   * 東武線駅ナンバリングの指定カラーに準拠（東上線・越生線 `#10428e`）。
4. **西武鉄道**:
   * 西武線ナンバリングの系統記号カラーに準拠（池袋線・西武有楽町線 `#ee7a00`）。
5. **東急電鉄 / 横浜高速鉄道**:
   * 公式ナンバリングカラーに準拠（東横線 `#da0042`、東急新横浜線 `#890d84`、みなとみらい線 `#1a55a1`）。
6. **相模鉄道**:
   * 相鉄公式駅情報ページ抽出カラーに準拠（本線・いずみ野線・新横浜線 `#0073bc`）。
7. **小田急電鉄**:
   * 小田急公式駅一覧ページ抽出カラーに準拠（小田原線・江ノ島線・多摩線 `#0085ce`）。
8. **首都圏新都市鉄道**:
   * TX公式路線図PDF抽出カラーに準拠（つくばエクスプレス `#014081`）。
9. **秩父鉄道**:
   * 公式駅情報ページ抽出カラーに準拠（秩父本線 `#01479d`）。
10. **JR西日本**:
    * JR西日本コーポレートカラー抽出値に準拠（大糸線西日本区間 `#0068b7`）。

## 3. アクセントカラー（accentColor）の選定基準

アクセントカラーは、地図上での識別性向上や、列車詳細パネル・種別バッジ表示等のUI表現において**路線の固有性・アイデンティティ**を補強するカラーとして設定されています。  
以下の4つの優先順位・パターンのいずれかに基づいて選定します。

### パターンA: 代表的な優等・速達列車種別のシンボルカラー
その路線で最も象徴的な看板速達種別や優等列車の案内色を採用する。
* **JR中央線（快速）**: `#c9252d`（中央特快・通勤特快などの特快レッド）
* **JR青梅線**: `#16a34a`（青梅特快のグリーン）
* **JR埼京線・川越線**: `#007ac1`（快速ブルー）
* **東京メトロ副都心線**: `#e05a00`（急行オレンジ）
* **東急東横線・みなとみらい線**: `#ea5504`（特急オレンジ）
* **秩父鉄道**: `#dc2626`（急行秩父路レッド）

### パターンB: 相互直通・接続相手路線のシンボルカラー
運行系統上密接に直通運転を行う相手路線、または接続路線のシンボルカラーを採用する。
* **JR中央本線（中央東線）**: `#f15a22`（ブルーの中距離電車に対し、東京方面直通・接続先の中央快速線オレンジバーミリオン）
* **JR武蔵野線**: `#c9252d`（オレンジの武蔵野線に対し、東京駅・海浜幕張方面直通先である京葉線のワインレッド）
* **相鉄・JR直通線**: `#002b66`（埼京線エメラルドに対し、直通先である相鉄の YOKOHAMA NAVYBLUE）

### パターンC: 企業のコーポレートカラーや車両帯のツートンカラー
車両帯に施されたペアカラーや、ブランドのコーポレートサブカラーを採用する。
* **東武東上線・越生線**: `#ed6d00`（東武フューチャーブルーに対する「東武ブライトオレンジ」）
* **つくばエクスプレス**: `#df0011`（TXディープブルーに対するペアカラー「TXスカーレットレッド」）
* **西武池袋線・西武有楽町線**: `#003a8c`（池袋線系統カラーに対する西武鉄道のシンボル「西武ブルー」）
* **相模鉄道各線**: `#008cd6`（新標準色のネイビーに対し、相鉄グループシンボルカラー「相鉄ブルー/スカイブルー」）
* **東京臨海高速鉄道りんかい線**: `#00a3af`（70-000形車両の帯色であるターコイズブルー）
* **JR八高線**: `#e06a3b`（キハ110系気動車や電化区間車両の帯色であるテラコッタオレンジ）

### パターンD: 同色または案内用濃淡シェード（単一ラインカラー線区）
特段の優等列車やデュアルカラーが存在しない場合、ラインカラーと同色または視認性調整用の同系シェードを採用する。
* **東京メトロ千代田線** (`#00bb85`) / **有楽町線** (`#c1a470`)
* **JR常磐線各線** (`joban_local`: `#9e9e9f`, `joban_rapid`: `#00c18a`, `joban_toride_iwaki`: `#0071c5`)
* **小田急電鉄各線** (`#0085ce`)
* **JR大糸線**（東日本 `#957490` / 西日本 `#0068b7`）

## 5. 新規路線追加時のカラー決定手順

新規路線を追加する際は、以下のステップに従って決定してください：

1. **メインラインカラー（lineColor）**:
   - ニコニコ大百科「鉄道路線のラインカラー一覧」を照合し、公式Webサイト・駅ナンバリングサインシステムから抽出されたHEXカラーコードを採用する。
2. **アクセントカラー（accentColor）**:
   - 上記の4つの選定方針（パターンA: 看板優等種別、パターンB: 直通先路線色、パターンC: 車両帯ツートン/企業色、パターンD: 同色設定）から最も適した意味づけを選び、定義ファイル内にコメントとともに記述する。
3. **ナンバリングバッジ（Badges.tsx）**:
   - [`src/components/Common/Badges.tsx`](file:///c:/Users/Genbu/GitHub/github.com/GenbuHase/Trainfo/src/components/Common/Badges.tsx) の `STATION_BADGE_COLORS` に新路線の駅ナンバリング記号と配色を追加する。
4. **デバッグページでの確認**:
   - ブラウザで `#debug` を開き、新路線のカードおよびカラーパレットで意図通りの配色・コントラストでレンダリングされているか確認する。
