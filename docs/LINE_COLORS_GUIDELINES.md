# 🎨 路線カラー・列車種別カラー設定ガイドライン (Line & Train Type Color Guidelines)

本ドキュメントでは、Trainfo プロジェクトにおける各路線の基本カラー（`lineColor` / `accentColor`）および列車種別カラー（`trainTypes[type].bgColor` / `textColor`）の設定方針と、実装時に遵守すべきデザイン・視認性ルールを定義します。

---

## 1. 基本思想：公式案内カラーの再現とUI視認性の両立

Trainfo では、地図上のポリライン・列車マーカー・タイムライン・時刻表バッジにおいて、ユーザーが直感的に路線や種別を識別できるよう、**各鉄道事業者が駅掲出の時刻表・路線図・車両案内表示（方向幕・LCD）で使用している公式カラー**を忠実に再現することを原則とします。

一方で、白背景のカードやダークトーンのバッジ上で文字が読めなくなる事態を防ぐため、**WCAG コントラスト基準を意識した明度・彩度調整**を併用します。

---

## 2. カラープロパティの役割分担

各路線定義（`Line` オブジェクト in `src/data/lines/*.ts`）には、以下の3種類のカラー設定が存在します。

| プロパティ名 | 主な使用箇所 | 設定基準 |
| :--- | :--- | :--- |
| **`lineColor`** | ・地図上の路線ポリライン（線路）<br>・路線選択ボタンのテーマ色<br>・駅詳細パネルのヘッダー帯 | 各路線の**公式コーポレートカラー／路線記号カラー**を設定します。<br>（例：山手線 `#80c241`、銀座線 `#f39700`、東武東上線 `#004098`、東武スカイツリーライン `#226bb8`） |
| **`accentColor`** | ・路線ポリラインのハイライト／縁取り<br>・グラデーションや強調UI要素 | 原則として `lineColor` と同色、またはその路線の**代表的な優等種別カラー／副次シンボルカラー**を設定します。<br>（例：中央線快速は `lineColor: #eb5c01` に対し `accentColor: #c9252d`、東北新幹線ははやぶさグリーン `#41934c` に対しはやぶさピンク `#e4007f`） |
| **`trainTypes[key].bgColor`** | ・地図上の列車アイコンの外枠／背景<br>・列車詳細パネルの種別バッジ<br>・駅時刻表の種別インジケーター | 各事業者の**公式停車駅案内図・時刻表における種別色**を設定します。<br>（`local` の設定ルールについては次節を参照） |
| **`trainTypes[key].textColor`** | ・種別バッジ内のテキスト色 | 原則として白（`#ffffff`）を使用します。ただし背景色が高明度（黄色 `#ffd400` や `#ffcc00` 等）の場合は、視認性確保のため濃色（`#1e293b` 等）を指定します。 |

## 3. 各駅停車・普通列車（`local` / `regular`）のカラー設定ルール

各駅停車（または普通列車）のバッジ背景色（`trainTypes.local.bgColor`）については、路線ごとの特性と公式案内の慣例に従い、以下の **2パターン** を使い分けます。

### パターンA：路線カラー（`lineColor`）と同色にするケース（標準）
単一系統で運行される路線や、各駅停車が路線そのものの象徴となっている路線では、`local.bgColor` に `lineColor` と同じ色（または同系色）を指定します。

* **適用例**:
  * **JR山手線**: `#80c241`（ウグイス）
  * **JR京浜東北・根岸線**: `#00b2e5`（スカイブルー）
  * **東京メトロ銀座線 / 丸ノ内線 / 日比谷線 / 東西線 / 千代田線 / 有楽町線 / 半蔵門線 / 南北線 / 副都心線**: 各路線カラーと同色
  * **小田急各線**: `#2288cc`（小田急ブルー）
  * **相鉄各線**: `#041452`（相鉄ネイビー）

### パターンB：公式の種別専用色（グレー・黒・青・別系統色など）にするケース
優等列車が多数走る複々線・幹線や、公式の路線図・時刻表で「各駅停車（普通）」に路線カラーとは異なる固有の色が割り当てられている路線では、**公式の種別色**を優先します。

* **適用例**:
  * **JR中央線快速 (`chuo`) / 青梅線 (`ome`) / 五日市線 (`itsukaichi`) / 中央本線 (`chuo_main`)**:
    * 快速（`rapid`）がオレンジバーミリオン（`#eb5c01` / `#f15a22`）を使用するため、各駅停車（`local`）には落ち着いたスレートグレー（`#475569`）、中距離の普通列車（`regular`）には中距離電車ブルー（`#0072bc` / `#0071c5`）を割り当てて明確に区別。
  * **JR総武快速線 (`sobu_rapid`)**:
    * 快速（`rapid`）が横須賀・総武快速ブルー（`#0074be`）を使用し、データ上含まれる緩行線直通の各駅停車（`local`）には総武緩行線イエロー（`#ffc20e`）を設定。
  * **JR常磐線快速 (`joban_rapid`)**:
    * 快速（`rapid`）がエメラルドグリーン（`#00c18a`）、中距離の普通電車（`local`）が常磐線ブルー（`#0071c5`）を使用。
  * **東武鉄道 全13路線 (`tobu_skytree`, `tobu_isesaki`, `tobu_nikko`, `tobu_urban_park`, `tojo` 等) & 野岩鉄道 (`yagan`) & 会津鉄道 (`aizu`)**:
    * 東武鉄道および直通先の野岩・会津鉄道の公式停車駅案内図に準拠し、普通（`local`）には**ブラック（`#1e1c1c`）**を設定（準急＝緑 `#009966`、急行＝赤 `#ed1a3d`、快速急行/快速＝青 `#006699` との対比を明確化）。
  * **東急東横線 (`tokyu_toyoko`)**:
    * 路線カラーは東横線レッド（`#da0442`）だが、急行（`express: #ef3123`）との混同を避けるため、東急公式案内に準拠して各駅停車（`local`）には**ブルー（`#1359a9`）**を設定。
  * **つくばエクスプレス (`tsukuba_express`)**:
    * 公式時刻表・案内サインに準拠し、普通（`local`）には**ダークグレー（`#3e3a39`）**を設定（区間快速＝青 `#036eb8`、通勤快速＝オレンジ `#f39800`、快速＝赤 `#d20012`）。
  * **JR両毛線 (`ryomo`)**:
    * 路線カラーは両毛線イエロー（`#ffd400`）だが、普通列車（`local`）は白文字視認性と公式表示を考慮しグレー（`#808080`）を設定。
  * **秩父鉄道 (`chichibu`)**:
    * 路線カラーは濃紺（`#01479d`）、普通列車（`local`）は視認性の良いブルー（`#0073bc`）、急行秩父路はレッド（`#dc2626`）、SLパレオエクスプレスはブラウン（`#78350f`）を設定。

## 4. 優等種別（快速・急行・特急・新幹線等）のカラー設定規約

同一路線内に複数の優等種別が存在する場合は、以下の階層構造と各社公式ルールに従って色相を分散させます。

1. **新幹線愛称別カラー（`hayabusa`, `komachi`, `tsubasa`, `toki`, `kagayaki`, `hakutaka`, `asama`, `tsurugi`）**:
   * 新幹線では列車愛称そのものを種別キーとして扱い、車体塗色・公式案内色（はやぶさ＝常盤グリーン `#41934c`、こまち＝茜色 `#ed4399`/`#dc143c`、つばさ＝おしどりパープル/オレンジ `#ea5514`、とき・たにがわ＝朱鷺色 `#f58d79`、かがやき＝赤 `#b82e2e`、はくたか＝紫 `#6d3b84`、あさま＝青 `#0078b6`、つるぎ＝紺 `#1d3d63`）を再現します。
2. **共通定数・プリセット管理 (`src/data/trainTypePresets.ts`)**:
   * 特急および主要な優等種別（快速・特快・通勤快速・準急・急行等）の定義の散乱や微差・タイポ・直通先との色ズレを防ぐため、`TRAIN_TYPE_COLORS` 定数および以下の共通プリセット群から参照して指定することを原則とします。
     * **特急プリセット (`LIMITED_EXP_PRESETS`)**: `STANDARD`（首都圏標準レッド `#d32f2f`）、`CHUO`（中央線系統ワインレッド `#be123c`）、`NIIGATA`（新潟夕日柿色 `#c2410c`）、`JOBAN`（常磐線レッド `#e60012`）、`BOSO`（房総ブルー `#0074be`）、`CRIMSON`（内房・京葉クリムゾン `#c9252d`）、`TOBU`（東武レッド `#c8102e`）、`ODAKYU`（小田急バーミリオンオレンジ `#dd3c00`）
     * **JR首都圏快速プリセット (`JR_RAPID_PRESETS`)**: `STANDARD`（標準ブルー `#0073bc`）、`URBAN`（快速アーバン `#e65100`）、`RABBIT`（快速ラビット `#e65100`）、`ACTY`（快速アクティー `#e65100`）、`COMMUTER_RAPID`（通勤快速パープル `#7b1fa2`）、`SPECIAL_RAPID`（特別快速エメラルド `#00897b`）、`JOBAN_SPECIAL_RAPID`（常磐線特別快速ネイビー `#003366`）
     * **中央線特快・直通系統プリセット (`CHUO_PRESETS`)**: `LOCAL`（グレー `#475569`）、`RAPID`（公式オレンジバーミリオン `#eb5c01`）、`COMMUTER`（通快パープル `#9333ea`）、`SPECIAL_RAPID`（特快スカイブルー `#0284c7`）、`CHUO_SPECIAL_RAPID`（中央特快 `#0284c7`）、`OME_SPECIAL_RAPID`（青梅特快 `#16a34a`）、`COMMUTER_SPECIAL_RAPID`（通勤特快 `#dc2626`）、`LIMITED_EXP`
     * **東武鉄道系統プリセット (`TOBU_PRESETS`)**: `LOCAL`（ブラック `#1e1c1c`）、`SEMI_EXP` / `SECTION_SEMI`（グリーン `#009966`）、`EXPRESS` / `SECTION_EXP`（レッド `#ed1a3d`）、`RAPID`（快速ブルー `#006699`）、`SL_TAIJU`（漆黒ゴールド `#2b2b2b` / `#d4af37`）、`LIMITED_EXP`
     * **相鉄線系統プリセット (`SOTETSU_PRESETS`)**: `LOCAL`（ヨコハマネイビーブルー `#041452`）、`RAPID`（ブルー `#0072bc`）、`EXPRESS`（レッド `#e60012`）、`COMMUTER_EXP`（山吹オレンジ `#e08a00`）、`COMMUTER_LTD_EXP`（ピンク `#e5007f`）、`LIMITED_EXP`（オレンジ `#f39800`）
     * **東急・みなとみらい線プリセット (`TOKYU_PRESETS`)**: `EXPRESS`（レッド `#da0442`）、`COMMUTER_LTD_EXP` / `LTD_EXP`（オレンジ `#ea5504`）
     * **小田急電鉄系統プリセット (`ODAKYU_PRESETS`)**: `LOCAL`（ブルー `#2288cc`）、`SEMI_EXP` / `COMMUTER_SEMI`（グリーン `#009d6a`）、`EXPRESS` / `COMMUTER_EXP`（オレンジ `#ff5900`）、`RAPID_EXP`（アンバーオレンジ `#f3962c`）、`LIMITED_EXP`（ロマンスカー `#dd3c00`）
     * **直通ライナープリセット (`LINER_PRESETS`)**: `STRAIN`（ライムグリーン `#99cc00`）、`TH_LINER`（ディープレッド `#c8102e`）
3. **JR・私鉄の一般特急**: 原則として格調高い**レッド／クリムゾン系**（`#d32f2f`, `#e60012`, `#be123c`, `#c8102e`）または列車固有色（ロマンスカーのバーミリオンオレンジ `#dd3c00`、千代田線内ロマンスカーのメトロブルー `#006cb7`、総武本線・外房線の房総ブルー `#0074be`、新潟・信越系統「いなほ」「しらゆき」の夕日柿色 `#c2410c`）を使用します。直通系統（例: 中央線〜篠ノ井線〜大糸線、信越本線〜妙高はねうまライン、高崎線〜上越線）では同一プリセット定数を指定してカラーを統一します。
4. **S-TRAIN (`strain`)**: 西武・メトロ・東急・みなとみらい線すべてで共通の**ライムグリーン（`#99cc00`、枠線 `#7ca600`）**に統一します。
5. **SL列車 (`sl`, `sl_taiju`)**: 蒸気機関車を象徴する重厚な**チャコールブラック／ダークブラウン**（`#2b2b2b`, `#78350f`）を使用します。
6. **急行・快速急行・特別快速（`express`, `rapidExp`, `special_rapid`）**:
   * **急行 (`express`)**: 赤系（東武・東急・相鉄・秩父）またはオレンジ系（メトロ半蔵門線・副都心線・千代田線・西武・小田急）など、各社の公式案内色を厳守します。
   * **快速急行 (`rapidExp`)**: 西武池袋線はパープル（`#8b52a1`）、東武東上線はブルー（`#006699`）、小田急線はオレンジ（`#f3962c`）と、事業者ごとの固有色を設定します。
   * **特別快速 (`special_rapid`)**: JR中央線はスカイブルー（`#0284c7`、青梅特快はグリーン `#16a34a`、通勤特快はレッド `#dc2626`）、上野東京ライン・湘南新宿ライン・東海道線はティールグリーン（`#00897b`）、常磐線はネイビー（`#003366`）を設定します。
7. **準急・区間準急（`semiExp`, `commuter_semi`, `section_semi`）**:
   * 東武・西武・小田急・東京メトロ（千代田線・半蔵門線）・JR常磐緩行線のすべてにおいて、公式案内通り**グリーン／エメラルド系**（`#009966`, `#00cc99`, `#009d6a`, `#3cb371`）で統一されています。

## 6. 新規路線追加時のカラー設計チェックリスト

新しく路線を `src/data/lines/` に追加する際は、以下の項目を確認してください。

1. **`lineColor` の選定**:
   * 事業者の公式路線図・駅ナンバリング記号の枠色と一致しているか？
   * 地図背景（ライトモード／ダークモード双方）の上でポリラインが埋もれない十分な彩度・コントラストがあるか？（白や極端な淡色は避ける）
2. **公式駅ナンバリングバッジ（`src/components/Common/Badges.tsx`）との連動**:
   * **その路線に事業者が公式に導入している駅ナンバリングが存在するか？**
   * 公式ナンバリングが存在する路線のみ、`Badges.tsx` の `LINE_COLORS` マップにプレフィックスと `lineColor` を追加し、丸型／角丸四角型などの形状ルール（メトロ＝丸、JR＝角丸枠、東急・東武・小田急等＝各社スタイル）を設定すること。
   * **公式ナンバリングが存在しない路線**（新幹線、高崎線、両毛線、上越線、八高線、房総各線、東北・信越・北陸の一部路線など）では、内部管理用の駅ID（`TS01`, `TK01` 等）が公式ナンバリングとして誤表示されないよう、`Badges.tsx` には登録しないこと（詳細は `docs/ROUTE_EXPANSION_PLAYBOOK.md` 第33条を参照）。
3. **種別カラー（`trainTypes`）の網羅性とコントラスト**:
   * 時刻表JSON内に登場するすべての `type` キーが `trainTypes` に漏れなく定義されているか？（未定義キーがあるとフォールバック表示になるため注意）
   * 背景色（`bgColor`）が明るい黄色系（`#ffd400`, `#ffcc00` など）の場合、`textColor: '#1e293b'` などの濃色文字を指定しているか？
4. **直通運転先との整合性**:
   * 直通運転を行う路線間で、共通運行される種別（例：`strain` = `#99cc00`、東武〜野岩〜会津の `local` = `#1e1c1c` / `limitedExp` = `#c8102e` 等）の色が違和感なく繋がっているか？
