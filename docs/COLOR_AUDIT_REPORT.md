# 🔍 路線・列車種別カラー定義 公式準拠監査レポート (Color Audit Report)

本ドキュメントは、Trainfo に収録されている**全102路線（21事業者）**の路線カラー（`lineColor` / `accentColor`）および列車種別カラー（`trainTypes`）について、各鉄道事業者の公式案内（路線図・駅ナンバリング記号・方向幕・時刻表表示）との整合性を監査した結果をまとめたものです。

---

## 1. 監査サマリー

* **監査対象**: `src/data/lines/` 配下の全102路線モジュールおよび `src/components/Common/Badges.tsx`
* **評価基準**:
  1. **公式路線カラーとの一致**: 各社公式のコーポレートカラー・路線記号カラーに準拠しているか。
  2. **各駅停車（普通列車）の配色妥当性**: 路線カラーと同色にするか、公式の種別色（黒・グレー・青等）を採用するかが一貫しているか。
  3. **優等種別の識別性と階層性**: 同一路線内の複数種別（準急・急行・快速・特別快速・特急・新幹線愛称別等）が視覚的に明確に区別できるか。
  4. **テキスト視認性（コントラスト比）**: 黄色背景などの高明度バッジにおいて濃色テキスト（`#1e293b` 等）が適切に設定されているか。
