# 公式情報に基づかない路線・種別カラーリング監査レポート

本ドキュメントは、Trainfoに導入されている全48路線および全列車種別のカラー設定について、指定の情報源：
1. **優先①: [ニコニコ大百科「鉄道路線のラインカラー一覧」](https://dic.nicovideo.jp/a/%E9%89%84%E9%81%93%E8%B7%AF%E7%B7%9A%E3%81%AE%E3%83%A9%E3%82%A4%E3%83%B3%E3%82%AB%E3%83%A9%E3%83%BC%E4%B8%80%E8%A6%A7)**
2. **優先②: [Wikipedia「日本の鉄道路線ラインカラー一覧」](https://ja.wikipedia.org/wiki/%E6%97%A5%E6%9C%AC%E3%81%AE%E9%89%84%E9%81%93%E3%83%A9%E3%82%A4%E3%83%B3%E3%82%AB%E3%83%A9%E3%83%BC%E4%B8%80%E8%A6%A7)**

と突合し、**公式情報に直接基づいていない設定、公式情報自体が存在しない（未制定）設定、または実車・直通先のサインシステム等に準拠した設定**を網羅的にリストアップしてまとめた監査レポートです。

## 1. 監査結果の分類基準

本レポートでは、公式カラー一覧表と完全に一致していない項目を以下の5つのカテゴリーに分類しています。なお、全48路線のすべてにおいて種別定義ファイル（`trainTypes.ts`）が完備されていることを確認済みです。

| 分類記号 | 分類名 | 概要・発生要因 |
| :---: | :--- | :--- |
| **A** | **公式未制定路線** | ①・②ともに独立した路線ラインカラー一覧の掲載がない路線（社章・車体色等で補完） |
| **B** | **意図的な例外指定** | ユーザー指示により、実車表示（白地黒文字・黒地白文字）の再現を優先して黒ベースを維持した種別 |
| **C** | **線区別・実車案内準拠** | JR東日本など、全社共通の公式種別色一覧が存在せず、駅発車標や車両行先表示の案内色を採用している種別 |
| **D** | **相互直通案内色準拠** | 直通運転先（小田急線、西武線、埼京線など）の種別色・案内色を反映している種別 |
| **E** | **公式色欄空欄の補完** | 公式テーブルに種別名の掲載はあるが、カラーコードが空欄（例：東武川越特急）のため実車色で補完 |

## 4. 総括と対応方針

1. **全48路線の種別定義完備**:
   - 全48路線のすべてで `trainTypes.ts` が正常に定義されており、未定義路線は存在しません。
2. **路線カラー（分類Aの3路線）について**:
   - 秩父鉄道・りんかい線・相鉄JR直通線は公式一覧に独立したラインカラーが存在しないため、**現行の車体色・コーポレートカラー設定を維持することが最も合理的**です。
3. **東上線・越生線の普通（分類B）について**:
   - 快速急行（青）との識別性および実車のLED/幕表示の観点から、**黒ベース（`#1e1c1c`）の維持がベストプラクティス**です。
4. **JR東日本の速達種別（分類C）について**:
   - JR東日本には公式種別色一覧が存在しないものの、駅発車標や車両行先表示器で定着している案内色（中央特快スカイブルー、青梅特快グリーン、快速ブルー、大糸線特急レッド等）を精緻に再現しており、**ユーザーの直感的な案内として非常に高い完成度**にあります。
