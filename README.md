## 主な機能

### 1. 66事業者・全276路線の広域路線網

新幹線7路線をはじめ、首都圏のJR・私鉄・地下鉄・モノレール・新交通・ローカル線から北関東・甲信越・東北・東海・近畿・山陽エリアの接続路線まで、66事業者・全276路線を統合しています。

### 2. ターミナル駅での他路線時刻表への切り替え

複数の路線や事業者が乗り入れるターミナル駅（東京、新宿、渋谷、大宮、横浜、名古屋、京都、大阪、仙台、新潟、長野など）では、駅詳細パネルから同名の他社線や他路線の時刻表へボタン1つで切り替えられます。

### 3. 遅延ロードと加減速シミュレーション

- 全276路線の時刻表JSONを初期バンドルから分離し、表示中の路線データのみをオンデマンドで読み込んでメモリにキャッシュします。
- 選択路線の統合時刻表をメモ化するとともに、駅と列車のマーカーをキャッシュしてDOMの差分だけを更新します。設定画面では画面の更新頻度（10 / 20 / 30 / 60 / 120 FPS）を端末に応じて切り替えられます。
- 駅発着の前後区間ではスムーズステップ関数（$3t^2 - 2t^3$）を用いて速度を計算し、通過駅では巡航速度を保ったまま、停車駅では滑らかに減速・加速します。
- 土合駅や湯檜曽駅のように上り線と下り線でホームが大きく離れている駅では、ズームレベル14以上または駅選択時に両ホームのマーカーと連絡通路を展開表示します。

### 4. 会社別・エリア別の路線選択と表示絞り込み

- 路線選択パネルは全66事業者の一覧から選ぶ「会社別」と、関東（146路線）・甲信越（25路線）・東北（55路線）・東海（18路線）・近畿・関西（32路線）から選ぶ「エリア別」を切り替えられます。
- 路線名・事業者名・エリア名での入力検索に加え、特定の路線やグループの「のみ」ボタンでその対象だけを単独表示できます。
- 進行方向（全方向・上り・下り）および列車種別（全種別・優等・普通/各停）での絞り込みに対応しています。地図タイプも標準マップ、航空写真、ダークマップから選べます。

### 5. 列車追従と直通全区間タイムライン

- 選択した列車を地図の中央で自動追従します。追尾設定の「追尾中に他の列車を非表示にする」を有効にすると、対象列車（併結時は相手編成も含む）だけを地図上に残せます。
- 直通運転を行う列車を選択すると、現在走っている路線の停車駅一覧と、始発駅から終着駅までの全路線を通した停車駅一覧を切り替えられます。路線境界駅には路線カラー付きの境界区切りと種別・列車番号の変化が表示されます。
- 通過済み駅は折りたたんで直前1駅だけを表示する形と全駅展開を切り替えられ、併結運転を行う列車では連結相手の編成へ詳細表示を切り替えられます。

### 6. 試運転・臨時列車クリエイター

オリジナルの臨時列車や試運転列車を作成し、マップ上に走らせられる機能です。

- 複数路線をまたぐ直通ルートを構築でき、接続可能な他路線の候補提示と境界駅の自動調整に対応しています。
- 「種別標準」「全駅停車」「主要駅のみ停車」「始発・終着以外をすべて通過」の一括適用に加え、駅ごとの停車・通過切り替えと着発時刻・停車時間の手動編集ができます。
- 列車番号・列車名・編成両数（2 / 4 / 6 / 8 / 10 / 12 / 15両）・巡航速度（1〜400 km/h の数値入力または 30〜320 km/h のプリセット）・発車時刻に加え、種別名・略称・カラーを設定できます。
- 作成した列車プランをブラウザ（`localStorage`）に保存し、ドラッグ＆ドロップでの並び替えや名称変更、再設定ができます。

### 7. 時刻操作と遅延シミュレーション

- 04:00から翌04:00までの24時間サイクルで、スライダーや時間帯プリセット（早朝／始発、朝、昼、夕、深夜／終電、未明／夜行）から任意の時刻へ移動できます。
- 実時間同期に加え、`1x` から `3600x` まで12段階（1x / 2x / 5x / 10x / 30x / 60x / 120x / 300x / 600x / 1200x / 1800x / 3600x）の再生速度と一時停止に対応しています。
- 曜日による自動判定に加えて手動で平日ダイヤと土休日ダイヤを切り替えられ、遅延シミュレーション（定刻 / 全線+5分遅延 / 全線+15分大幅遅れ / ランダム局所遅延）も試せます。

### 8. 公式案内準拠の路線・種別カラー

各鉄道事業者の公式路線カラー・種別案内色と、公式駅ナンバリング制定路線におけるナンバリング配色を定義しています。詳細は [docs/LINE_COLORS_GUIDELINES.md](docs/LINE_COLORS_GUIDELINES.md) にまとめています。

## セットアップと起動方法

### 必要環境

- Node.js v20.0 以上推奨
- npm v10.0 以上

### 1. リポジトリのクローンと依存パッケージのインストール

```bash
git clone https://github.com/GenbuHase/Trainfo.git
cd Trainfo
npm install
```

### 2. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173/Trainfo/` を開くとアプリケーションが起動します。路線形状や種別カラーの確認用デバッグ画面は `http://localhost:5173/Trainfo/#debug`（または設定モーダル内のボタン）からアクセスできます。

### 3. 本番ビルドとプレビュー

```bash
# TypeScript型チェックと本番用バンドルの生成 (dist/ に出力)
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```

リポジトリには生成済みの時刻表JSON（`src/data/lines/<lineId>/`）が同梱されているため、通常のアプリ実行やビルドにAPIキーや外部サービス設定は不要です。

## 時刻表データの更新・保守用コマンド

時刻表データを再生成したり、直通運転・併結設定や品質監査を進めたりするときは次のコマンドを使います（手順の詳細は [docs/MAINTENANCE_GUIDE.md](docs/MAINTENANCE_GUIDE.md) と [docs/ROUTE_EXPANSION_PLAYBOOK.md](docs/ROUTE_EXPANSION_PLAYBOOK.md) に記載しています）。

### 直通運転リンク・併結処理・通過駅時刻補間の再実行

個別路線の時刻表を更新した後や、接続・併結ルールを変更した際は、以下のコマンドで全276路線の直通紐付け（`prevTripId` / `throughTripId`）、併結編成リンク（`coupling`）、駅発車標の再集約を一括更新できます。

```bash
node scripts/runThroughLinker.cjs
```

### キャッシュからの全路線一括再構築

ローカルキャッシュ（`scripts/cache/`）から全路線の時刻表生成と直通・併結リンカーを一括再実行する場合は以下を実行します。

```bash
node scripts/rebuildAllTimetablesFromCache.cjs
```

### 品質監査・整合性チェック

路線追加やダイヤ更新後に、駅座標のズレ、走行パスの連続性、直通・併結リンクの整合性、列車番号反映率を検査できます。

```bash
# 全路線の駅座標と線路ポリラインの乖離スキャン
npm run audit:stations

# 全路線の走行パス・セグメント接続の健全性監査
npm run audit:paths

# 全路線の併結列車および直通運転リンクの整合性監査
npm run audit:couplings

# 全276路線の時刻表・列車番号反映率の総合監査
node scripts/audit_all_lines_status.cjs
```
