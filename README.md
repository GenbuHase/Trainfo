### 2. 🏢 広域ターミナル・同名駅のクロスオーバーリンク
異なる路線や事業者が乗り入れるターミナル駅（東京・新宿・渋谷・池袋・品川・上野・大宮・横浜・新横浜・武蔵小杉・川崎・立川・八王子・高尾・大月・北千住・浅草・押上・秋葉原・西船橋・千葉・蘇我・取手・熱海・三島・国府津・小田原・高崎・福島・盛岡・新潟・直江津・長野・松本・塩尻・会津若松など）では、駅詳細パネルから**同名の他社線・他路線の発着時刻表へワンクリックで横断切り替え**が可能です。

### 3. ⚡ 高性能アーキテクチャ（遅延ロード・空間インデックス・スムーズ加減速）
* **時刻表データの動的遅延ロード（Lazy Loading）**: 全102路線の時刻表JSONを初期バンドルから分離し、表示中の路線のデータのみをオンデマンド取得・メモリキャッシュします。
* **ビューポートカリング & 空間インデックス**: 1,962駅の座標と走行中列車を空間フィルタリングし、画面表示領域（Viewport）内の要素のみをレンダリング。設定モーダルからアニメーションのリフレッシュレート（**10 / 20 / 30 / 60 / 120 FPS**）を端末性能に応じて切り替え可能です。
* **エルミート補間（Smoothstep）による加減速シミュレーション**: 駅発着時の前後区間でスムーズステップ関数（$3t^2 - 2t^3$）を用いた加減速計算を行い、通過駅では巡航速度を維持、停車駅では滑らかに減速・加速するリアルな列車挙動を実現しています。

### 4. 🎛️ 2モード路線セレクター（会社別 / エリア別）& マップ直結フィルタードック
* **🏢 会社別 / 🗺️ エリア別の2モード切替**:
  * **会社別モード**: 全21事業者のアコーディオンから路線を選択。
  * **エリア別モード**: **関東（首都圏・北関東：67路線）**・**甲信越（新潟・長野・山梨：16路線）**・**東北（福島・山形・秋田：14路線）**・**東海（静岡方面：5路線）**の4大エリアごとに路線を一括・個別フィルタリング可能。
* **インクリメンタル路線検索 & 「のみ」単独抽出**: 路線名・事業者名でのリアルタイム絞り込みに加え、特定の路線や事業者・エリアの「のみ」ボタンでワンクリック単独表示が可能です。
* **駅マーカー表示モード切替**: 地図上の駅ピン表示を「すべて表示 / 乗換駅のみ / 非表示」の3段階で切り替え可能。

### 5. 🎯 列車追従（トラッキング）& 直通全区間タイムライン
* **カメラ自動追従 & 単独追尾モード**: 選択した列車を地図の中央で滑らかに自動追従。「追尾中に他の列車を非表示」を有効にすると、対象列車（および併結相手編成）のみをマップ上に浮かび上がらせて鑑賞できます。
* **「〇〇線内 / 全区間」タイムライン切替**: 直通運転を行う列車では、現在走行中の路線内のみの停車駅一覧と、始発駅から最終目的地までの複数路線を貫通した**全区間タイムライン**をワンタップで切り替え可能。路線境界駅には路線カラー付きの直通セパレータ（種別・列車番号変化表示付き）が挿入されます。
* **通過済み駅のスマート折りたたみ**: 長距離列車でも現在の走行位置が即座に把握できるよう、通過済み駅を自動折りたたみ（直前1駅を残してグラデーション格納）し、ワンタップで全駅展開できます。

### 6. 🧪 試運転・臨時列車クリエイター
ユーザー自身がオリジナルの臨時列車・試運転列車を設計し、実際のダイヤが動くマップ上へ即座に発車させられるサンドボックス機能です。
* **複数路線直通ルート構築**: 1路線内の走行だけでなく、接続可能な他路線を自動レコメンドして複数路線をまたぐ直通ルート（境界駅の自動調整付き）を自在に構築可能。
* **停車駅パターンの柔軟なカスタマイズ**: 路線ごとの既存種別標準パターンのほか、「全駅停車」「主要駅のみ（乗換駅）」「ノンストップ（始発・終着のみ）」の一括適用、および駅ごとの「停車 / 通過」個別トグル・停車秒数や発着時刻のピンポイント編集に対応。
* **カスタム種別・編成スペック設定**: 列車番号・愛称（例: 試9501M「試運転」）・編成両数（1〜17両）・最高巡航速度（60〜320km/h）・発車時刻に加え、オリジナルの種別名・略称・テーマカラーをカラーピッカーで作成可能。
* **マイプリセット管理**: 作成した列車設定をブラウザ（`localStorage`）に保存し、ドラッグ＆ドロップでの並び替えやインライン名称変更、ワンクリックでの再出庫が可能です。

### 7. ⏱️ タイムコントロール（時計操作・倍速再生・ダイヤ切替）
* **任意の時刻へのジャンプ & スクラブ操作**: 早朝・朝ラッシュ・日中・深夜など、見たい時間帯へスライダーまたは時刻入力で即座にワープ可能。
* **再生スピード変更**: `1x`（実時間）から `5x` / `10x` / `30x` / `60x` / `300x` までの倍速再生および一時停止に対応し、広域ネットワークのダイナミックな列車流動を観察できます。
* **平日 / 土休日ダイヤ切替**: 曜日自動判定に加え、手動で平日ダイヤ・土休日ダイヤを即座に切り替え可能。

### 8. 🎨 公式準拠の運行系統カラーリング
* **路線・種別カラーの徹底再現**: 各鉄道事業者の公式路線カラー・種別案内色（東武本線の普通列車ブラック `#1e1c1c`、JR中央線の快速オレンジ／各駅停車イエロー／普通中距離ブルー、新幹線の列車愛称別カラーなど）を全102路線にわたり厳密に定義（詳細は [`docs/LINE_COLORS_GUIDELINES.md`](docs/LINE_COLORS_GUIDELINES.md) 参照）。

## 🔧 時刻表データの更新・メンテナンス用コマンド

時刻表データの再生成や直通運転・併結設定の更新、品質監査を行う場合は、以下のスクリプトを使用します（詳細は [`docs/MAINTENANCE_GUIDE.md`](docs/MAINTENANCE_GUIDE.md) および [`docs/ROUTE_EXPANSION_PLAYBOOK.md`](docs/ROUTE_EXPANSION_PLAYBOOK.md) を参照してください）。

### 環境変数の設定（ODPT APIから新規取得する場合のみ）
プロジェクトルートに `.env` ファイルを作成し、公共交通オープンデータセンター（ODPT）のAPIキーを設定します。

```env
ODPT_API_KEY_DEFAULT=your_standard_api_key
ODPT_API_KEY_CHALLENGE=your_challenge_2025_api_key
```

> **💡 Note**: リポジトリには生成済みの時刻表JSON（`src/data/generated/`）が同梱されているため、通常のアプリ実行やビルドにはAPIキーは**不要**です。

### 直通運転リンク・併結処理・通過駅時刻補間の再実行
個別路線の時刻表を更新した後や、接続・併結ルールを変更した際は、以下のコマンド1つで全102路線の直通紐付け（`prevTrainId` / `nextTrainId`）・併結編成リンク（`coupledWith`）・通過駅の推定通過時刻補間（`passingStopTimes`）を一括更新できます。

```bash
node scripts/runThroughLinker.cjs
```

### キャッシュからの全路線一括再ビルド
ローカルキャッシュ（`scripts/.cache/`）から全路線の時刻表生成と直通・併結リンカーを一気通貫で再実行する場合は以下を実行します。

```bash
node scripts/rebuildAllTimetablesFromCache.cjs
```

### 品質監査・整合性チェックスクリプト
路線追加やダイヤ更新後に、駅座標のズレ・走行パスの不連続・直通や併結のリンク不整合を自動検査する監査コマンドを用意しています。

```bash
# 全路線の駅座標と線路ポリラインの乖離スキャン
npm run audit:stations

# 全路線の走行パス・セグメント接続の健全性監査
npm run audit:paths

# 全路線の併結列車および直通運転リンクの整合性監査
npm run audit:couplings

# 全102路線の時刻表・運行ステータスの総合監査
node scripts/audit_all_lines_status.cjs
```
